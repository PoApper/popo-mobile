## 환경설정

`.env.example`을 따라 `.env`를 만들어 필요한 값들을 채워넣습니다. 해당 파일은 안드로이드 빌드 시 사용됩니다.

`.env.dev.example`, `.env.prod.example`을 확인한 후 `.env.dev`, `.env.prod`로 이름을 변경합니다. 로컬 애뮬레이터 실행 시, dev/prod 빌드 시 사용됩니다. 더 많은 내용은 `/android` `/ios`의 `README.md` 참고
